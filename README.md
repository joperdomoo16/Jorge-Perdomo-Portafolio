# Portafolio de Desarrollo Web y Móvil 🚀

Bienvenido al código fuente de mi portafolio profesional. Este proyecto es una Single Page Application (SPA) diseñada para exhibir mis habilidades en desarrollo Front-End, Back-End y diseño UI/UX.

## 🛠️ Stack Tecnológico
*   **Lenguajes:** HTML5 Semántico, CSS3, JavaScript (ES6+).
*   **Arquitectura:** Diseño modular con separación estricta de *assets*, lógica (`js/`) y estilos (`css/`).
*   **Optimización:** Archivos SVG extraídos para aligerar el DOM y lógica unificada en `ui-interacciones.js` para reducir peticiones HTTP.
*   **Despliegue:** CI/CD integrado mediante GitHub Pages.

## 🌟 Características Destacadas
*   **Diseño Minimalista e Interactivo:** Interfaz fluida basada en principios de diseño responsivo.
*   **Consumo Dinámico de Datos:** Renderizado de proyectos y habilidades inyectado desde estructuras de datos en `js/data-portafolio.js`.
*   **Validaciones en Cliente:** Formularios protegidos mediante scripts propios (`js/validaciones.js`).
